Мониторинг вакансий HR-менеджера

Еженедельная система поиска вакансий HR-направления (junior/entry) в Алматы и Астане — чтобы ни одна релевантная вакансия не осталась незамеченной.

Версия 1.0 Статус: Draft Алматы · Астана
⬇ Скачать Excel-трекер Репозиторий на GitHub

О проекте

Вакансии рассеяны по множеству источников (агрегаторы, госпортал, LinkedIn, соцсети, карьерные страницы компаний), и ни один источник не покрывает 100% рынка. Этот проект — инструмент/процесс, который еженедельно собирает открытые вакансии по специальности HR-менеджер (и смежным ролям) в Алматы и Астане, группирует их по отраслям и компаниям и выдаёт готовый список новых вакансий с рекомендациями, куда откликаться в первую очередь.

Еженедельный цикл (≤ 30 минут)

  • Получение уведомлений от источников в течение недели (email / RSS / push)
  • Точечная проверка карьерных страниц компаний без агрегаторов
  • Внесение новых вакансий в журнал, статус по умолчанию «Новая»
  • Дедупликация вакансий, встретившихся на нескольких агрегаторах
  • Присвоение приоритета (Высокий / Средний / Низкий)
  • Обновление статусов вакансий из предыдущих недель
  • Отклики по вакансиям с высоким приоритетом в первую очередь
